# Kente Play Together internet relay

This runs the room-code signaling API over HTTPS and a coturn TURN relay for players whose routers cannot establish a direct WebRTC connection. The host still runs PCSX2 locally and streams that session to one remote Player 2. The relay does not host games or ROMs.

## Requirements

- A Linux VPS with a public IPv4 address and Docker Compose.
- Two DNS A records pointing to that VPS: one for `LOBBY_DOMAIN`, one for `TURN_DOMAIN`.
- Firewall/security-group ingress: TCP 80 and 443 for Caddy; UDP and TCP 3478 plus UDP 49160–49200 for TURN. TCP 443/UDP 443 also supports HTTPS and HTTP/3 at Caddy.
- The VPS provider must permit the TURN relay port range. If it cannot, configure a different supported TURN provider and set `KENTE_TURN_URLS`/credential issuance accordingly.

## Launch

1. Copy `.env.example` to `.env`, set both DNS names and the server's real public IPv4, and replace `TURN_SECRET` with a random secret (`openssl rand -hex 32`). Keep `.env` private.
2. From this directory run `docker compose up -d --build`.
3. Check `https://<LOBBY_DOMAIN>/api/lobby/health` returns `{"ok":true,...}`.
4. In Kente, both players enter `https://<LOBBY_DOMAIN>` in **Lobby Server**. The host creates a room and shares the URL plus room code. The host must have the PS2 game installed locally; the guest joins, readies up, then the host starts.

Caddy obtains and renews HTTPS automatically when DNS points to the server and ports 80/443 are reachable. TURN credentials are generated by the lobby service as expiring HMAC credentials; the shared secret is only present on the server. TURN traffic is encrypted by WebRTC's DTLS-SRTP transport, while the signaling endpoint is protected by HTTPS.

Rooms are currently in-memory, limited to two players, and disappear if the relay restarts. Rate limits are process-local. This is a small self-hosted MVP, not a multi-instance production service. Do not expose the standalone API without HTTPS or put it behind an untrusted proxy. Choose a VPS and domain you control; no public service is provisioned by the app.
