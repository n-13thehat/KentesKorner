Thought for 7s
Yeah — that can be a real project.

Kente’s Corner could be a USB-bootable retro gaming shell built on Batocera as the base OS, with your own branded frontend, curated launcher flow, and optional metadata/content hooks that point to material hosted on Internet Archive. Batocera is designed to run from a USB drive or other external storage, and its docs also support keeping games/media on separate external storage if you want a cleaner modular setup. 

The part I’d be careful about is how Internet Archive is used. Building a launcher that helps users access public-domain, homebrew, freeware, personal backups, and legally distributable content is one thing; building a product around pulling copyrighted commercial ROMs is where you can run into copyright trouble. Even Internet Archive’s own community/legal-facing material distinguishes the legality of emulators from the legality of downloading game ROMs. 

A strong version of this project would look like this:

Core idea
A branded Batocera USB image called Kente’s Corner that boots straight into your own experience:

custom splash screen and theme

“vault” style game browser

controller-friendly UI

curated collections

legal-content mode by default

optional network features for updates, box art, manuals, and links

Best architecture

Batocera as the base for hardware compatibility, emulation stack, controller support, and USB boot. Batocera supports installation/boot from USB and has standard methods for adding BIOS files and game files. 

Custom theme / shell layer for Kente’s Corner branding.

Content indexer that reads a local catalog file instead of scraping live every time.

Legal library sources only by default: public-domain games, freeware, homebrew, DOS/shareware where allowed, user-supplied backups.

Optional second-drive storage so the OS stays on one USB and large content lives on another drive. Batocera documents external storage workflows for this. 

What makes it hard

making the UI feel custom instead of “just Batocera with a skin”

maintaining clean metadata

controller-first navigation

boot reliability across PCs

staying on the right side of copyright

Also, Batocera notes some real-world boot caveats: on recent x86/x86_64 PCs you may need to disable Secure Boot, and some devices/drives can be finicky about USB boot behavior.

What I would not build
I would not make the centerpiece “download commercial ROMs from Internet Archive.” That is the fastest way to create legal and platform risk. Safer is:

user imports their own files

your catalog surfaces legal/open content

your shell supports metadata, manuals, and historical material

you can link outward instead of bundling questionable files

Tech stack

Base OS: Batocera

Frontend/theme: EmulationStation theme system + custom assets

Scripting: Bash/Python for indexing, startup logic, and updater

Metadata: JSON or SQLite

Optional web backend: lightweight API for catalog updates and featured content
